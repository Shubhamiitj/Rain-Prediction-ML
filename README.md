# Rain Prediction Using Machine Learning

## Project Overview

This project predicts whether it will rain tomorrow using weather data.

## Features

* Location
* Temperature
* Humidity
* Wind Speed
* Precipitation
* Cloud Cover
* Pressure

## Machine Learning Model

* Logistic Regression

## Frontend

* Streamlit

## Project Files

* app.py
* model.pkl
* scaler.pkl
* columns.pkl

## How to Run

pip install -r requirements.txt

python -m streamlit run app.py

## Accuracy

100%
